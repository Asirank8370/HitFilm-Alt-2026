## 🎞️ Workflow Basics

HitFilm organizes your work into several areas. Knowing these areas helps you create content effectively:

*   Media Panel: Stores your video clips, images, and audio tracks.
*   Trimmer: Used to select specific parts of a raw video file before adding them to the project.
*   Timeline: The workspace where you arrange your clips in order. The timeline runs from left to right.
*   Viewer: Shows you what the video looks like as you make changes.
*   Effects Panel: Contains tools for color, light, and motion manipulation.
*   Export Tab: Used to save your final project as a finished video file.

## 💡 Troubleshooting Common Issues

If you run into issues, check these settings:

*   Software will not open: Ensure your Windows operating system is up to date. Sometimes, missing system updates prevent software from launching.
*   Lag while editing: Close other programs like web browsers or games. High-resolution video editing uses significant system memory.
*   Export errors: Check your disk space. Ensure the drive where you save your project has enough room for the final video file.
*   Missing audio: Check your track settings in the timeline. Ensure the track is not muted.
